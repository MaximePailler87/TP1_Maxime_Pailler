## Ceci est le projet pour le TP 1 du module selenium python

Ce code a pour but de vérifier plusieurs fonctionnalités du site the-internet.herokuapp.com

Le programme _main.py_ fait appel aux programmes suivants :
* _login_page.py_ pour tester la possiblité de se connecter et se déconnecter avec des identifants donnés
* _dropdown_page.py_ pour tester la possibilité de sélectionner une option parmi une liste déroulante
* _add_remove_page.py_ pour tester la capacité à ajouter puis supprimer un certain nombre d'éléments via des boutons.
